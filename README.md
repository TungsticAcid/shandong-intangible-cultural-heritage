# 齐鲁非遗图志 · 山东非遗地图

一个以山东省地图为主入口的非物质文化遗产（非遗）H5 交互页面。在地图上缩放、平移、点击 16 个设区的市与 136 个县（市、区），查看落在每一方水土上的**国家级、省级、市级、县级**非遗代表性项目，并尽可能回到官方公开来源。

---

## 功能

- **地图寻访**：滚轮缩放、拖拽平移、双指捏合、双击放大；点击县区查看项目。
- **市域 / 县区下钻**：点击城市标签进入市域，再点击县区；地址栏同步 `#/map/370700/370703`，可直接分享。
- **两种着色**：按县区条目数量，或按县区主门类着色；图例同步。
- **四级名录检索**：按名称、保护单位、技艺关键词、门类、城市、级别、批次筛选。
- **门类图谱**：十个门类的数量结构与代表项目。
- **项目档案**：级别、四级批次、公布年份、申报地区、保护单位、分布县区、官方来源；国家级项目保留官方简介，市级/县级记录单列。
- **响应式**：桌面三栏；移动端地图 + 城市快捷条 + 详情上滑面板 + 底部导航。
- **离线可用**：不依赖 CDN、外部字体或运行时接口；双击 `index.html` 即可打开（官方来源链接需联网）。

### 县级覆盖（16 / 136）

济南市中区、槐荫区；青岛崂山区、市南区、平度市；烟台芝罘区；潍坊寒亭区、青州市；济宁曲阜市；泰安岱岳区；临沂兰山区；德州夏津县；滨州惠民县；菏泽定陶区、郓城县；东营广饶县。

> 其余 120 个县区暂未找到可逐条核验的县级公开名录；页面保留其国家/省/市级项目，并明确标注“县级名录暂未接入”，**没有编造县级项目**。

### 为什么是“项目条目”，不是官方项目总数

公开名录会把“主项、扩展项、不同子项名称、多个保护单位”拆成多条记录；不同级别也会重复收录同一项目。本页按**项目名称 + 归属地**合并去重，得到 5,844 条展示条目。它不等于官方认定的项目总数，也不代表四级名录的官方累计数。

## 本地运行

直接双击 `index.html`，或在本目录启动静态服务器：

```bash

# 打开 http://localhost:8080/
```

页面不依赖构建步骤、包管理器或环境变量。

## 技术实现

- 原生 HTML / CSS / ES5 JavaScript；无框架、无构建步骤、无运行时外部依赖。
- 行政边界在构建阶段预投影为 Web Mercator，并简化为 SVG path；运行时只做 SVG `transform`。
- 滚轮 / 双指缩放、拖拽、双击、键盘操作；标签在屏幕空间做碰撞避让。
- 数据内嵌于 `js/data.ich.js`；检索为纯前端内存过滤。
- 视觉为宣纸、墨线、朱砂、黛青；所有图形为原创 CSS/SVG，不使用第三方非遗照片。
- 路由：`#/`、`#/map`、`#/map/<市>`、`#/map/<市>/<县区>`、`#/index`、`#/cats`、`#/about`。

## 已知限制

1. **5,844 条是四级去重条目，不是官方项目总数**。
2. **5 个市只接入最新批次**：枣庄、潍坊、临沂、德州、聊城；历史批次尚未补齐。
3. **县级覆盖 16/136**：其余 120 个县区暂未找到可逐条核验的县级公开名录，页面标注“暂未接入”，不编造项目。
4. 市级/县级记录没有可靠的公开简介；页面只展示名录信息与保护单位，不生成替代性叙述。
5. 地图边界为示意性矢量，不作为国界、行政区划或权属依据；正式出版、展览或政务使用请使用标准地图并取得审图号。
6. 名录会更新；本页是某一时点的公开数据快照。
